Un poco de ayuda con Fiivi

Fiivi es proporcionado por Anthony Dale Pancho, en California, Estados Unidos. Para recibir soporte o realizar solicitudes de privacidad, escribe a getfiivi@gmail.com.

¿Algo no funciona?

Cuéntanos qué ocurrió, qué esperabas, el modelo de tu dispositivo y las versiones de iOS/iPadOS y Fiivi. Una captura de pantalla puede ayudar; oculta primero los detalles privados del plan. No envíes contraseñas, tokens de inicio de sesión, datos de tarjetas de pago ni información sensible innecesaria. Envía un archivo del planificador solo si decides compartir deliberadamente su contenido pertinente para recibir soporte. No se promete un plazo de respuesta concreto.

Gestionar una suscripción

En Ajustes del iPhone o iPad, toca tu nombre → Suscripciones → Fiivi. También puedes seguir las instrucciones de cancelación de Apple o solicitar un reembolso elegible a Apple. Eliminar Fiivi o sus datos de planificación no cancela la suscripción. Los derechos aplicables del consumidor siguen vigentes.

Restablecer el acceso o tu plan

Restore Purchases («Restaurar compras») comprueba el acceso a la suscripción con Apple. No restaura los datos de planificación. Estas instrucciones cubren la configuración local del planificador Fiivi, que no ofrece inicio de sesión en cuentas de Fiivi ni sincronización en la nube.

Mientras tengas acceso a la aplicación, You → File backup → Save a Fiivi file («Tú → Copia de seguridad en archivo → Guardar un archivo Fiivi») permite guardar una copia antes de cambiar de dispositivo. Utiliza Restore from a saved Fiivi file («Restaurar desde un archivo Fiivi guardado») para importar un archivo compatible. Revisa la confirmación: importar reemplaza el plan de este dispositivo, y Fiivi conserva primero una copia local de recuperación. Las copias de seguridad y la migración de dispositivos de Apple son servicios independientes. No se garantiza una copia de seguridad ni una restauración satisfactoria.

Eliminar datos locales o consultar sobre privacidad

Mientras tengas acceso a la aplicación, You → File backup → Delete local data («Tú → Copia de seguridad en archivo → Eliminar datos locales») restablece los datos de planificación guardados y las copias internas de recuperación. Las exportaciones guardadas/compartidas, copias temporales de exportación, copias de seguridad externas y facturación de la suscripción son independientes. Si el acceso ha caducado, contacta con nosotros para recibir orientación. Eliminar la aplicación no cancela la facturación ni borra las copias de seguridad externas. No podemos recuperar ni borrar a distancia un planificador que haya permanecido únicamente en tu dispositivo.

Escribe a getfiivi@gmail.com sobre información que enviaste a soporte o una inquietud de privacidad. Consulta la Política de privacidad para conocer el tratamiento y las opciones, y las Condiciones de uso para las suscripciones y la licencia Apple de la aplicación.
