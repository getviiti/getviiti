Un peu d’aide pour Fiivi

Fiivi est fourni par Anthony Dale Pancho, en Californie, aux États-Unis. Pour l’assistance ou les demandes de confidentialité, écrivez à getfiivi@gmail.com.

Quelque chose ne fonctionne pas ?

Décrivez ce qui s’est passé, ce que vous attendiez, le modèle de votre appareil et les versions d’iOS/iPadOS et de Fiivi. Une capture d’écran peut aider ; masquez d’abord les détails privés de votre programme. N’envoyez pas de mots de passe, jetons de connexion, informations de carte de paiement ou informations sensibles inutiles. Envoyez un fichier de planification uniquement si vous choisissez délibérément de partager son contenu pertinent pour l’assistance. Aucun délai de réponse particulier n’est promis.

Gérer un abonnement

Dans les réglages de l’iPhone ou de l’iPad, touchez votre nom → Abonnements → Fiivi. Vous pouvez aussi suivre les instructions d’annulation d’Apple ou demander un remboursement admissible à Apple. Supprimer Fiivi ou ses données de planification n’annule pas l’abonnement. Les droits applicables aux consommateurs restent en vigueur.

Rétablir l’accès ou votre programme

Restore Purchases (« Restaurer les achats ») vérifie l’accès à l’abonnement auprès d’Apple. Cette action ne restaure pas les données de planification. Ces instructions couvrent la configuration locale du planificateur Fiivi, qui ne propose ni connexion à un compte Fiivi ni synchronisation dans le nuage.

Tant que vous avez accès à l’application, You → File backup → Save a Fiivi file (« Vous → Sauvegarde de fichier → Enregistrer un fichier Fiivi ») permet d’enregistrer une copie avant de changer d’appareil. Utilisez Restore from a saved Fiivi file (« Restaurer depuis un fichier Fiivi enregistré ») pour importer un fichier compatible. Lisez la confirmation : l’importation remplace le programme de cet appareil, et Fiivi conserve d’abord une copie locale de récupération. Les sauvegardes et migrations d’appareils Apple sont des services distincts. Aucune sauvegarde ni restauration réussie n’est garantie.

Supprimer les données locales ou poser une question de confidentialité

Tant que vous avez accès à l’application, You → File backup → Delete local data (« Vous → Sauvegarde de fichier → Supprimer les données locales ») réinitialise les données de planification enregistrées et les copies internes de récupération. Les exports enregistrés/partagés, copies temporaires d’export, sauvegardes externes et facturation de l’abonnement sont distincts. Si l’accès a expiré, contactez-nous pour obtenir des conseils. Supprimer l’application n’annule pas la facturation et n’efface pas les sauvegardes externes. Nous ne pouvons pas récupérer ni effacer à distance un planificateur resté uniquement sur votre appareil.

Écrivez à getfiivi@gmail.com au sujet d’informations envoyées à l’assistance ou d’un problème de confidentialité. Consultez la Politique de confidentialité pour le traitement et les choix, et les Conditions d’utilisation pour les abonnements et la licence Apple de l’application.
